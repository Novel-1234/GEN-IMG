## GPT2WEB image archive

The initial migration contains 3971 unique original images and matching WebP previews. Originals are byte-identical to the verified sources. `manifest.json` is a migration snapshot listing their SHA-256, dimensions and pinned commit paths; later uploads are indexed by the GPT2WEB gallery database. Images in this repository are public; review choices and conversation metadata remain outside this repository.
